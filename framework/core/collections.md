# Zongsoft.Collections

`Zongsoft.Collections` 提供集合增强、层级集合、参数集合、同步集合和常用集合扩展，是很多框架内部对象树和配置树的基础。

## 主要职责

* 提供分类、层级、参数、队列、字典等集合类型。
* 提供集合事件、集合工具和枚举扩展。
* 支撑逻辑路径、命名集合、同步访问和只读包装等常见集合场景。
