# Zongsoft.Common

`Zongsoft.Common` 放置核心类库中最通用的工具类型和扩展方法，包括类型转换、随机、校验、序列、时间、字符串、URI 和类型别名等基础能力。

## 主要职责

* 提供增强版 `Convert`、`Randomizer`、`EnumUtility` 等常用工具。
* 提供字符串、数组、日期时间、类型、URI 等扩展方法。
* 提供校验码、顺序号、别名集合、位向量和注解工具。
* 为上层模块减少对重复小工具类的散落依赖。
