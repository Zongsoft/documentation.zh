# Zongsoft.Flowing

`Zongsoft.Flowing` 提供轻量状态机和状态图模型，用于表达状态、状态向量、状态上下文、状态处理器和状态流转。

## 主要职责

* 定义状态机、状态图、状态上下文和状态处理器接口。
* 提供 `StateMachine`、`StateDiagramBase`、`StateHandlerBase` 等基础实现。
* 支持将状态流转逻辑从业务对象中抽离出来。
* 适合用于工作流片段、任务状态、设备状态或业务状态迁移。
