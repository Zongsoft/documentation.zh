# Zongsoft.Resources

`Zongsoft.Resources` 提供资源定位、资源访问和资源工具方法，用于统一处理本地化文本、嵌入资源或其它可定位资源。

## 主要职责

* 定义资源对象和资源定位器抽象。
* 提供默认资源定位和资源访问辅助方法。
* 支持调用方按名称、文化或上下文查找资源。
* 为本地化和模块化资源管理提供基础模型。
