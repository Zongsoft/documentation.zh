# Zongsoft.Scheduling

`Zongsoft.Scheduling` 提供调度器、触发器、触发器构建器、延迟和 Cron 表达式等基础类型，用于表达定时或延迟执行。

## 主要职责

* 定义 `IScheduler`、`ITrigger`、`ITriggerBuilder` 等调度抽象。
* 提供触发器选项、延迟触发和 Cron 表达式支持。
* 为后台任务、工作者和宿主程序提供通用调度入口。
