# Zongsoft.Text

`Zongsoft.Text` 提供文本模板、模板格式化、文本正则表达式和部分中文、URI、Web 文本处理辅助能力。

## 主要职责

* 定义文本模板和模板格式化接口。
* 提供基于正则表达式的文本处理模型。
* 提供中文、URI、Web 等文本辅助类型。
* 为命令、配置、消息或输出格式化提供轻量文本处理能力。
