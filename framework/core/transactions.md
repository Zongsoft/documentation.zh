# Zongsoft.Transactions

`Zongsoft.Transactions` 提供轻量事务抽象、事务状态、隔离级别、事务行为和事务参与登记模型，用于表达应用层事务。

## 主要职责

* 定义事务对象、事务信息、事务状态和隔离级别。
* 支持事务行为、登记上下文和事务参与者。
* 为数据服务、批处理和跨组件操作提供统一事务抽象。
