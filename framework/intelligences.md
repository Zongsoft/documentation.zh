# 智能化

`Zongsoft.Intelligences` 提供 AI 相关插件能力，包括大语言模型、助手、会话和聊天接口。当前 README 中重点描述了基于 Ollama 协议栈的本地模型接入。

## 典型流程

1. 安装并启动 Ollama。
2. 拉取本地模型，例如 `qwen3:0.6b`。
3. 部署 `Zongsoft.Intelligences` 插件。
4. 通过终端命令或 RESTful API 调试助手、模型和会话。

## 接口形态

- 终端命令：用于模型列表、模型安装、会话打开、聊天等操作。
- RESTful API：用于助手、模型、会话、历史记录和聊天。
