# 插件应用模型

插件式应用由宿主程序、插件框架、插件模块和应用上下文组成。

## 宿主程序

宿主程序负责启动进程并建立运行环境。它通常只包含 `Program.cs`、项目文件、部署脚本和基础配置。

## 应用上下文

应用上下文表示当前运行中的应用实例。它包含应用名称、标题、版本、环境、模块集合、服务提供器和运行时属性。

Web 宿主中的 `/Application` 接口会返回当前应用上下文的基本信息。

## 模块

插件加载后会形成应用模块。模块可以暴露事件、服务、命令、控制器或其它能力。

Web 宿主中的 `/Modules` 接口可用于查看当前加载的模块信息。

## 服务

插件可以向应用注册服务。服务由应用上下文统一解析和管理，供命令、事件处理器、Web 控制器或其它模块使用。
