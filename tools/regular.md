# 正则表达式工具

`Zongsoft.Tools.Regular` 是一个 Windows GUI 正则表达式测试器。

## 主要用途

- 编写和测试正则表达式。
- 验证匹配结果。
- 测试替换逻辑。
- 切换常用 `RegexOptions`。
